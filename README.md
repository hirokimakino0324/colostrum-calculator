# 初乳給与量シミュレーター

子牛に「何を・何L（何袋）・いつ」飲ませればよいかを、その場で計算するWebアプリです。
牛舎のスマホでの利用を想定した単一HTMLファイル（Tailwind CSS + JavaScript）で、インストール不要・オフラインでも動作します。

## 使い方

1. **目標とする血清IgG濃度**を選ぶ（10 / 20 / 30 g/L）
2. **出生後の経過時間**を入力する
3. **初乳のBrix値（％）**を入力する（初乳がない場合は 0）

→ 結果がリアルタイムで表示されます。

## 計算の考え方

| 項目 | 式・値 |
| --- | --- |
| 必要な吸収IgG量 (g) | 目標血清IgG (g/L) × 血漿量 (L) |
| 血漿量 (L) | 体重 (kg) × 9% |
| 初乳中IgG濃度 (g/L) | Brix (%) × 2.7 − 10 （Brix 22% ≒ 50 g/L） |
| 吸収率 AEA | 出生直後 約35%、以降は時間とともに低下、24時間で腸管閉鎖 |
| 給与量 (L) | 必要吸収IgG ÷ (初乳IgG濃度 × その時点の吸収率) |

- **Brix 22%未満**：品質不足の警告とともに、初乳製剤の必要**袋数**を表示します。
- **Brix 22%以上**：必要初乳量(L)を表示します。1回の上限は **4L**。超える場合は「〇時間後にあと〇L」の分割スケジュールを、そのときの低下した吸収率で再計算して表示します。
- 十分量が確保できている場合も、追加給与を推奨する案内を表示します。

「詳細設定」から、子牛の体重・初乳製剤1袋あたりのIgG量・分割給与の間隔を農場に合わせて変更できます。

## 公開方法（GitHub Pages）

リポジトリの Settings → Pages → Source を `main` ブランチのルートに設定すると、そのまま公開されます。

## 開発用サブエージェント

`.claude/agents/` に、このアプリを保守するための Claude Code サブエージェント定義を置いています。

| エージェント | 役割 |
| --- | --- |
| `colostrum-integrator` | 統合担当。各担当の報告を裁定し、実装に反映する |
| `colostrum-literature` | 初乳・移行免疫の文献担当。数値の根拠を出典付きで示す |
| `colostrum-logic-verifier` | 計算ロジック検証担当。式・境界条件・分割給与を検算する |
| `colostrum-ux-designer` | デザイン担当。牛舎スマホでの可読性・操作性を評価する |

## 注意

本アプリが示す値は**目安**です。最終的な判断は獣医師および農場のプロトコルに従ってください。
初乳製剤の1袋あたりIgG量は、必ずお使いの製品の表示に合わせて設定してください。
