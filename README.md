# 初乳給与量シミュレーター

子牛に「何を・何L（何袋）・いつ」飲ませればよいかを、その場で計算するWebアプリです。
牛舎のスマホでの利用を想定した単一HTMLファイル（Tailwind CSS + JavaScript）で、インストール不要・オフラインでも動作します。

## 使い方

1. **目標とする血清IgG濃度**を選ぶ（10 / 20 / 30 g/L）
2. **出生後の経過時間**を入力する
3. **初乳のBrix値（％）**を入力する（初乳がない場合は 0）

→ 結果がリアルタイムで表示されます。

## 計算の考え方

| 項目 | 式・値 | 主な根拠 |
| --- | --- | --- |
| 体内に入れたいIgG量 (g) | 目標血清IgG (g/L) × 血漿量 (L) | AEAの標準定義式 |
| 血漿量 (L) | 体重 (kg) × 9% | Quigley ら 1998, J Dairy Sci 81:1308 |
| 初乳中IgG濃度 (g/L) | Brix (%) × 6.8 − 100（22% ≒ 50、25% ≒ 70、30% ≒ 104） | Sockett ら 2023, Front Vet Sci のカットオフに整合 |
| 吸収率 AEA | 〜2h: 35%／〜12h: 緩やかに低下（12hで約17%）／12〜24h: 急速に低下（24hで約3%） | Fischer ら 2018、Stott ら 1979 |
| 1回の上限 | min(4L, 体重×10%) | Chigerwe ら 2008 ほか。黒毛和種では自動的に下がる |
| 給与量 (L) | 体内に入れたいIgG ÷ (初乳IgG濃度 × その時点の吸収率) | — |

### 初乳3Q「量」のフロア

セミナー資料で示されている体重比の累積給与量を**下限**として組み込んでいます。目標IgGから計算した量がこれを下回る場合は、この量まで引き上げて表示します。

| 時間 | 最低 | 理想 | 40kgの子牛 |
| --- | --- | --- | --- |
| 6時間以内 | 体重の5% | 10% | 2〜4L |
| 12時間以内（累計） | 10% | 15% | 4〜6L |
| 24時間以内（累計） | 15% | 20% | 6〜8L |

結果画面に達成状況のパネルを表示します。Brixが高いと必要量が少なく計算されるため、このフロアがないと「飲ませ足りない」指示になりかねません。

- **Brix 22%未満**：品質不足の警告とともに、初乳製剤の必要**袋数**を表示します。手元の初乳を一緒に飲ませた分のIgGは差し引いて計算します。
- **Brix 22%以上**：必要初乳量(L)を表示します。1回の上限を超える場合は「〇時間後にあと〇L」の分割スケジュールを、そのときの低下した吸収率で再計算して表示します。目標に届かない場合は併用すべき製剤の袋数を出します。
- **生後24時間以降**：腸管が閉じIgGは吸収されないため、達成量の計算は行わず「獣医師にすぐ連絡」を表示します。
- 十分量が確保できている場合は、追加給与を推奨する案内を表示します。

「詳細設定」から、子牛の体重・初乳製剤1袋あたりのIgG量・1袋を溶かす湯量・分割給与の間隔を農場に合わせて変更できます。

### 注意点

- Brix値からのIgG推定は誤差が大きく（±40 g/L級）、あくまで目安です。
- **黒毛和種の初乳はホルスタインの約2倍のIgGを含む**という報告があり（北海道立畜産試験場 2005）、ホルスタイン由来のBrix換算式は和牛では過小評価になる可能性があります。
- 代用初乳（リプレーサー）は1回分 IgG 100〜150 g、補助剤（サプリメント）は40〜60 g程度です。**補助剤は単独では受動免疫を成立させられません。**
- 血清IgGの評価区分は Excellent ≥25／Good 18〜24.9／Fair 10〜17.9／Poor <10 g/L（Lombard ら 2020, J Dairy Sci 103:7611）。

## 公開方法（GitHub Pages）

リポジトリの Settings → Pages → Source を `main` ブランチのルートに設定すると、そのまま公開されます。

## 開発用サブエージェント

`.claude/agents/` に、このアプリを保守するための Claude Code サブエージェント定義を置いています。

| エージェント | 役割 |
| --- | --- |
| `colostrum-integrator` | 統合担当。各担当の報告を裁定し、実装に反映する |
| `colostrum-literature` | 初乳・移行免疫の文献担当。数値の根拠を出典付きで示す |
| `colostrum-logic-verifier` | 計算ロジック検証担当。式・境界条件・分割給与を検算する |
| `colostrum-ux-designer` | デザイン担当。牛舎スマホでの可読性・操作性を評価する |

## 注意

本アプリが示す値は**目安**です。最終的な判断は獣医師および農場のプロトコルに従ってください。
初乳製剤の1袋あたりIgG量は、必ずお使いの製品の表示に合わせて設定してください。
